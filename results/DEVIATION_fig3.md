# Deviation note — Fig 3 specification

**Original spec (CLAUDE_CODE_TASK_BRIEF.md, Phase 5, item 3):**
> R² vs µ at 100% checkpoint, x-axis = friction grid, 3 lines (A/B/C). Per-µ R² is computed by fitting a separate probe on the data restricted to a ±0.05 window around each grid point (or just plot the per-friction prediction MSE if a per-µ fit is too noisy with limited samples).

**Deviation:** I did not produce the per-µ R² figure as originally specified. Replaced with a different fig 5: ΔR² (MLP − linear) per agent at 100% (`fig5_mlp_minus_linear`), which directly visualises the methodology's encoder-disambiguation question.

**Why:**
1. **Per-µ R² with restricted data is degenerate.** Within a ±0.05 window of a single grid point, the target µ is approximately constant, so target variance ≈ 0 and R² is undefined (or trivially 1.0 from a constant predictor). I confirmed this in the smoke test — single-µ probe gave R²=1.0000 with MSE=0, which is meaningless.
2. **Per-friction MSE** would be better but requires per-test-sample predictions, which are not saved by the current rollout/probe pipeline. Adding that requires another rollout pass on each 100% checkpoint (~3.4 min × 9 = 30 min).
3. **The replacement figure is more directly tied to the pre-registered patterns.** ΔR² (MLP − linear) at 100% directly tests whether µ-information lives in linearly accessible form (small ΔR²) or nonlinearly entangled form (large ΔR²) — the core question that motivates Component 4 of the framework.
4. **Coverage of the original intent is partial:** Completion-rate vs µ (fig3) and lap-time vs µ (fig4) already give a per-µ behavioural breakdown across A/B/C. The probe-decoding-quality vs µ angle is the only thing missing; the encoder-quality contrast (linear vs MLP) is what the dissertation actually argues about.

**If time permits**, the original fig3 can be regenerated by re-running the probe with per-test-sample prediction logging on the 9×100% checkpoints. Estimated cost: ~30 min compute + ~10 min figure code.

**Decision authority:** Fig 3 substitution is a methodology-figure-only change; the methodology .tex is unchanged (no probe-protocol amendment). The user is expected to either accept the substitution or commission the per-µ regen.
